# Alumni Database Management System

## Project Description

A secure web-based Alumni Database Management System with improved validation.

## Features

- Alumni registration
- Input validation
- Duplicate email checking
- Alumni search
- Display alumni information

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

- src/index.html - User interface
- src/style.css - Styling
- src/script.js - Application logic
- tests/ - Test files
